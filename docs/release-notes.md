CodeWith's first public release: a standalone, self-hosted specification and AI planning workspace.

- Requirements, acceptance criteria, references, questions, tasks and revision history.
- Per-user Codex, Claude Code and direct API connections.
- Configurable evaluation policies with system → workspace → specification inheritance.
- Planning improvement loops with explicit targets, blockers, progress and stop reasons.
- Versioned HTML plans, human review, final approval and browser completion records.
- Personal/shared/server deployment modes and configurable authentication.
- English default UI, Korean selection, themes and responsive layouts.
- Removed obsolete local-bridge and IDE-plugin coupling.
- npm package, prebuilt application ZIP, checksums, and GitHub Actions CI/CD.

Requires Node.js 22.13+; no AI subscription, credentials, user data or test certificate is included. The ZIP is the simplest unauthenticated download. The npm package is hosted on GitHub Packages, which requires registry authentication.

Assessments are AI judgments, not project test results. Live provider authentication and physical passkeys should be verified in your deployment.
